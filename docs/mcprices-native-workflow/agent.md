# McPrices Change Agent Rules

## Always Follow
- Do not violate any of our previous rules.
- Design must be as attached.
- We are implementing this as a native part of the Kadence parent theme.
- Keep in mind: do not create it as a child theme.
- We are going to create it 100% Kadence theme native part.
- Exact same as attached files.
- 100% working with WordPress admin panel customization like drag and drop.
- All plugins compatible as far as the native Kadence approach allows.
- Header, footer, and body must stay customizable from the WordPress panel just like the original theme.
- Never try to integrate as child theme.
- The user must later be able to update prices/content from WordPress admin without deployment and without writing code.

## Working Method
- Read `spec.md` before every change batch.
- Keep `implementor.md` current with the real implementation details.
- Use `reviewer.md` after each major feature pass.
- Update `status.md` with scores and misses.
- Follow `orchestrator.md` from start to finish.

## Quality Bar
- Native first.
- Visual parity first.
- Admin editability first.
- No shortcuts that reduce maintainability.
